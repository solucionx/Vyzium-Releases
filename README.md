Vyzium Releases

Repositório público de distribuição do Vyzium.

Este repositório é destinado somente aos instaladores e arquivos necessários para atualização automática do aplicativo.

Downloads

As versões publicadas ficam disponíveis na seção Releases deste repositório.

O código-fonte principal do Vyzium não é distribuído por este repositório.

Arquivos de atualização

Uma release do Windows pode conter:

Vyzium-Setup.exe

Vyzium-Setup.exe.blockmap

latest.yml

Esses arquivos são utilizados pelo instalador e pelo mecanismo de atualização automática do Vyzium.
